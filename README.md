# PNB-STOCK-ANALYSIS-DASHBOARD

## Project Overview
This project focuses on analyzing Punjab National Bank (PNB) stock market data through an interactive dashboard.

## Key Features
- Open Price and Close Price KPIs
- Monthly and daily filters
- Closing Price trend analysis
- Delivery Percentage analysis
- Turnover visualization

## Key Learnings
- Data analysis
- Data visualization
- Financial data interpretation
- Interactive dashboard development
